What this console does

It sends a release package to this server, waits for the validation, and shows the report. It is the same API that the nightly pipeline uses.

Who you are

The gateway authenticates you and gives the server your name, your roles and your token. This page holds no password and no token. If your session ends, reload the page and the gateway sends you to the login page.

The phases of a validation

ARCHIVE_STRUCTURAL
Reads the zip. Checks file names, columns and field types.
SQL
The assertion groups. This is the largest part.
DROOL_RULES
Content rules. Switched off unless you ask for them.
MRCM
Checks attributes against the machine-readable concept model.
TRACEABILITY
Compares the content with the authoring history.

Result counts

Failures are assertions that found content problems. An incomplete assertion did not finish, and this is a fault in the validation, not in the content. A failure count of -1 means the assertion did not run to completion, so read the message.

Other interfaces

Swagger UI gives every endpoint and its parameters. OpenAPI gives the machine description.

Validation running
